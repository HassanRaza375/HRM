# Performance & KPI user guide

The Performance workspace is available from **HCM → Performance**. It is designed for HR and managers to define KPIs, record review results, and view a concise organisation-level summary. All data is stored in this browser's local storage, so it is not shared with other browsers or devices.

## 1. Performance overview

Open **HCM → Performance → Overview** to see the current state of the appraisal process.

- The top cards show active KPIs, completed reviews, draft reviews, and the average score from completed reviews.
- **Department performance** groups completed reviews by the saved department and calculates their average weighted score.
- **Recent reviews** opens an individual, read-only review page when selected.
- Use **Manage reviews** to create or update a review.

This page starts showing department insight only after at least one review is marked **Completed**.

## 2. KPI Library

Open **HCM → Performance → KPIs** before creating reviews.

1. Select **Add KPI**.
2. Enter a clear KPI name, target, unit, and weight. A KPI weight must be between 1 and 100.
3. Optionally set a department or role. Leaving either field blank makes that KPI applicable more broadly.
4. Set the review frequency and keep its status **Active**.
5. Select **Save KPI**.

Use the search and filters to find an existing KPI. Inactive KPIs are retained for reference but cannot be added to a new review. Deleting a KPI does not change KPI snapshots already stored in past reviews.

## 3. Employee Performance / review register

Open **HCM → Performance → Employees Performance** to manage review records.

### Create a review

1. Select **New review**.
2. Choose the employee and enter a period, for example `Q3 2026`.
3. The system automatically adds active KPIs matching the employee's department and designation, plus company-wide KPIs.
4. Use **Add KPI** to include any other active KPI, or the remove button beside a row to remove one from this specific scorecard.
5. Record the actual result and enter a score from 0 to 100 for each KPI.
6. Add manager comments or development actions.
7. Save as **Draft** while work is in progress, or mark it **Completed** when final.

The overall score is calculated as a weighted average of the included KPI scores. Ratings are assigned automatically:

| Score | Rating |
| --- | --- |
| 90–100 | Outstanding |
| 75–89 | Exceeds expectations |
| 60–74 | Meets expectations |
| 40–59 | Needs improvement |
| 0–39 | Unsatisfactory |

Use the employee, department, period, and status filters to find reviews. The pencil icon edits a review and the delete icon removes it permanently from this browser.

## 4. Review detail

Open a review from **Recent reviews** on the overview page.

This page shows the review's saved employee details, overall weighted score, rating, manager comments, and the complete KPI-by-KPI scorecard. Use **Edit review** to return to the review register with that review opened in the editor.

## Recommended workflow

1. Create company, department, and role-specific KPIs.
2. Create a review for each employee and save it as a draft.
3. Review results with the manager, complete the scores and comments, then mark the record completed.
4. Use the overview to spot department trends and outstanding drafts.
